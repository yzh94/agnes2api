# 需求文档：AI 驱动桌面宠物行为系统

## 功能概述

将桌面宠物从"静态心情指示器"升级为"有情境意识的陪伴者"，通过调用 Agnes 文本模型，根据时间、系统状态、用户习惯动态生成宠物的行为和对话。

## 核心需求

### FR-1 宠物尺寸放大
- 当前 SVG 显示尺寸为 80x94px，需放大至 160x190px（2倍）
- 保持 SVG viewBox 不变，仅修改 CSS 尺寸
- 新增动作层 SVG 元素（手、脚、头部动态变化）

### FR-2 AI 行为决策
- 新增 `POST /api/manage/pet/act` 接口
- 接受上下文数据（时间、统计数据、历史记录）
- 调用 Agnes 文本模型生成宠物行为指令
- 超时保护（3秒），失败降级为本地规则

### FR-3 上下文感知触发
- 每 30 秒定期检查
- 页面从 hidden → visible 时触发
- 成功率骤变（±30% 阈值）时触发
- 饭点/整点/午夜等时间点触发
- 用户 10 分钟未交互时触发

### FR-4 动作丰富化
- 支持 12+ 种动作：idle/wave/eat/type/sleep/look/jump/point/dance/stretch/think/surprised/worried/panic
- 每种动作对应独立的 CSS 动画 + SVG 元素变化
- 气泡文案动态化（来自 LLM，非硬编码）

### FR-5 时间/习惯场景
| 时间段 | 行为 |
|--------|------|
| 06:00-08:00 | greeting + 挥手 |
| 11:30-12:30 | eating + 提醒吃饭 |
| 12:30-13:30 | eat + 轻松文案 |
| 14:00-17:00 | type + 鼓励文案 |
| 18:00-19:00 | eating + 提醒吃饭 |
| 22:00-00:00 | worried/sleeping + 别太晚 |
| 00:00-06:00 | sleeping（强制） |
| 成功率 > 95% | celebrating + 庆祝 |
| 成功率骤降 > 30% | panic + 提醒 |
| 周末 | 更轻松活泼 |
| 30min+ 未交互 | thinking/sleeping |

## 非功能性需求

- NFR-1：LLM 调用超时 3 秒，失败返回默认 idle 动作
- NFR-2：历史记录存 localStorage，跨会话保留
- NFR-3：气泡文案不超过 18 字
- NFR-4：不影响现有宠物拖拽、点击交互功能
